# my-cv

Personal CV + portfolio site for Matías Rodríguez — AI/Backend/LLMs.

Static site built with Next.js (App Router, `output: 'export'`), Tailwind CSS v4, shadcn/ui, and next-themes. Deployed to Firebase Hosting.

## Features

- Dark / light theme
- Bilingual: ES 🇦🇷 / EN 🇺🇸
- Nav modes: top bar, sidebar, collapsed icon rail (persisted in localStorage)
- Interactive project accordion

## Dev

```bash
make dev      # serve on port 3013
make open     # open browser
make deploy   # build + firebase deploy
```

## Stack

- Next.js 15 · React 19 · TypeScript
- Tailwind CSS v4 · shadcn/ui
- next-themes · lucide-react
- Firebase Hosting
